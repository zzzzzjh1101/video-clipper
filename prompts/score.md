# 爆点评分 Prompt（独立重打分用）

你是短视频流量分析师。下面是候选切片列表（含起止时间、原文摘录、原评分）。
请基于以下四维重新打分（0-1），并给出修正理由。

## 四维评分
1. **信息价值**：独特见解 / 信息密度 / 实用 / 反常识
2. **情感共鸣**：爽 / 笑 / 怒 / 好奇 / 共鸣 / 吃瓜
3. **传播潜力**：金句 / 梗 / 争议 / 可讨论 / 可转发
4. **结构完整**：有始有终，起承转合

## 判定基准（平台实战经验）
- 0.9+ 必爆：强金句 + 强情绪 + 前 3 秒钩子（如「今天直接给你干到 39 块 9」+ 逼单氛围）
- 0.75-0.9 优质：完整高能/干货，可稳定出量
- 0.5-0.75 及格：有看点但缺钩子或太散
- <0.5 不建议切：平淡、冗长、无记忆点

## 输出（严格 JSON）
```json
{"scores": [{"index": 0, "score": 0.88, "type": "金句", "reason": "修正理由（15-30字）"}]}
```
