# 切片类型百科 —— 直播/长视频切什么、怎么切

> 依据：抖音/快手切片号运营实践、直播切片分销玩法（2025 年切片传播已成汽车/电商营销标配）、autoclip/PreenCut 等开源项目的类型化 prompt 设计。
> 每种类型 = 判定特征 + 切点选择 + 成片策略 + LLM 分析侧重。

## 总原则

- **切片本质**：把直播/长视频里的「高信息密度 + 高情绪浓度」段落剪成 15s-3min 的短视频。
- **前 3 秒定生死**：钩子（悬念/冲突/福利/金句）必须在开头 3 秒内出现，否则完播率崩。
- **一段一主题**：每条切片只讲一件事（一个卖点/一个观点/一个笑点），主题杂 = 完播率差。
- **情绪 > 信息**：爆款切片 70% 靠情绪（爽、笑、怒、共鸣），30% 靠信息。

---

## 1. 电商带货 ecommerce（直播切片分销主力）

- **切什么**：商品核心卖点、价格机制（到手价/优惠券）、逼单话术、使用效果展示、福利/限量氛围。
- **判定特征**：「上链接」「XX到手价」「今天给到」「福利」「库存不多」「拍一发三」、倒计时、价格对比。
- **切点选择**：从「卖点抛出」切到「价格/逼单收尾」；必须保留价格信息，删寒暄。
- **成片策略**：15-45s；字幕放大价格数字；结尾挂小黄车提示。
- **分析侧重**：信息价值（卖点密度）+ 传播潜力（价格冲击力）。

## 2. 娱乐综艺 entertainment

- **切什么**：笑点完整闭环（铺垫→爆发→反应）、名场面、游戏环节高潮、嘉宾互动火花、意外翻车。
- **判定特征**：笑声、起哄、吐槽、反转、游戏规则揭晓时刻。
- **切点选择**：笑点前保留必要铺垫（1-2s），切到「观众/嘉宾反应」结束；绝不在笑点中间切断。
- **成片策略**：20-60s；可加效果音（duang/笑声）；字幕配吐槽文字。
- **分析侧重**：情感共鸣 + 结构完整。

## 3. 游戏高光 game

- **切什么**：五杀/团灭、极限反杀、翻盘时刻、天秀操作、名场面（Bug 级演出）、高能语音互动。
- **判定特征**：击杀提示音、解说/队友高亢语音、连杀播报、弹幕刷屏时刻。
- **切点选择**：操作开始前 1-2s → 结算/反应结束；保留击杀音效。
- **成片策略**：15-40s；竖屏裁掉非关键 UI；可加 KILL 特效字。
- **分析侧重**：情感共鸣（爽感）+ 传播潜力。

## 4. 知识干货 knowledge

- **切什么**：方法论、信息差、反常识观点、案例拆解、避坑清单、步骤教学。
- **判定特征**：「记住」「核心是」「其实」「第一步」「重点」「踩过坑」「信息差」。
- **切点选择**：观点抛出 → 论证完整闭环；一条切片一个知识点，讲透为止。
- **成片策略**：1-4min（知识类可以长）；字幕整句完整；可加要点卡片。
- **分析侧重**：信息价值（密度）+ 结构完整。
- **注**：知识类用「钩子前置」——先抛结论/反常识，再展开论证。

## 5. 观点输出 opinion

- **切什么**：鲜明观点、争议话题、犀利吐槽、金句输出、站队表态。
- **判定特征**：「我觉得」「凭什么」「就是」「最烦」「说句难听的」、排比金句。
- **切点选择**：观点首发 → 论证/举例 → 金句收尾；保留完整论证链，删铺垫。
- **成片策略**：30-90s；金句做字幕高亮；争议类标题用问句。
- **分析侧重**：传播潜力（争议度）+ 情感共鸣。

## 6. 演讲口播 speech

- **切什么**：金句、排比高潮、情绪爆发、号召性结尾、动人故事片段。
- **判定特征**：排比句式、停顿蓄力、语调升高、掌声、背景音乐渐强。
- **切点选择**：蓄力开始 → 金句落地 + 反应；保留掌声/呼吸。
- **成片策略**：20-60s；配 BGM 情绪推高；金句大字幕。
- **分析侧重**：情感共鸣 + 传播潜力。

## 7. 故事剧情 story

- **切什么**：悬念设置、剧情转折、真相揭晓、高潮冲突、结尾反转。
- **判定特征**：「结果」「没想到」「后来」「关键的是」、语速加快、背景音乐切换。
- **切点选择**：转折前留钩子 → 揭晓完整；断在悬念处引导看全集。
- **成片策略**：30-90s；可做「未完待续」结尾钩子。
- **分析侧重**：结构完整 + 情感共鸣。

## 8. 才艺表演 talent

- **切什么**：高光段落（副歌/绝活/大招）、观众反应、翻车又救场。
- **判定特征**：音乐高潮、欢呼声、动作幅度加大。
- **切点选择**：高光前 1s → 表演结束 + 欢呼收尾；保留现场氛围。
- **成片策略**：15-45s；竖屏居中裁切；可加舞台感调色。
- **分析侧重**：情感共鸣 + 结构完整。

## 9. 直播互动 live_interaction（连麦 / PK / 多人同框）

- **切什么**：连麦对话爆点、PK 名场面（比分反超/惩罚环节）、吵架/对峙、打赏感恩瞬间、粉丝互动高能。
- **判定特征**：≥2 个说话人、情绪冲突、PK 倒计时、礼物特效音。
- **切点选择**：冲突/话题引入 → 交锋结束；双方发言都要完整，保留反应声。
- **成片策略**：20-60s；**必须跑音色分离**，字幕带说话人标签（`[主播]` `[连麦]`）；可加分屏提示「左/右」。
- **分析侧重**：情感共鸣（冲突张力）+ 传播潜力（争议/吃瓜属性）。
- **注**：PK/吵架类切片是平台流量密码（吃瓜心理），但注意平台违规边界（辱骂、低俗）。

## 10. 产品体验 experience

- **切什么**：开箱、使用痛点、真实效果对比、踩坑吐槽、长期使用反馈。
- **判定特征**：「我用了」「真的」「踩坑」「刚开始以为」。
- **切点选择**：痛点抛出 → 体验过程 → 结论；删冗长操作过程。
- **成片策略**：30-90s；效果对比做分屏。
- **分析侧重**：信息价值 + 情感共鸣（共鸣感）。

## 11. 内容评测 review

- **切什么**：对比结论、榜单、避雷/推荐、参数解读。
- **判定特征**：「对比」「总结」「推荐」「不推荐」「第一名」。
- **切点选择**：结论先行 → 关键对比论据；删测试过程。
- **成片策略**：30-120s；榜单字幕逐条弹出。
- **分析侧重**：信息价值 + 结构完整。

## 12. 情感陪伴 emotion

- **切什么**：走心语录、深夜电台式独白、情感故事、治愈瞬间。
- **判定特征**：慢语速、背景音乐、低音、长停顿。
- **切点选择**：情绪进入 → 金句落地；保留呼吸和停顿。
- **成片策略**：20-60s；配情绪 BGM；字幕字号大、字距宽。
- **分析侧重**：情感共鸣（强）。

## 13. 新闻资讯 news

- **切什么**：事件核心、关键信息、权威表态、现场画面。
- **判定特征**：事件描述、时间地点、人名职务。
- **切点选择**：信息完整的一句话到一段话；不加工、不加戏。
- **成片策略**：15-45s；字幕信息点高亮；注明来源。
- **分析侧重**：信息价值 + 传播潜力（时效）。

## 决策速查（agent 判断类型时用）

| 信号 | 类型 |
|---|---|
| 有「上链接/到手价/福利」 | ecommerce |
| 有笑声/起哄/反转 | entertainment |
| 有击杀音效/连杀 | game |
| 有「记住/第一步/核心」 | knowledge |
| 有「我觉得/凭什么」 | opinion |
| 有排比+升调+掌声 | speech |
| 有「结果/没想到/后来」 | story |
| 有音乐高潮+欢呼 | talent |
| ≥2 个说话人+冲突/PK | live_interaction |
| 有「我用了/踩坑」 | experience |
| 有「对比/推荐/总结」 | review |
| 慢语速+低音+BGM | emotion |
| 事件+时间地点 | news |
